CampusBites ORM Queries
=======================

1. Count all menu items and list those with price greater than 450.
Statement:
MenuItem.objects.count()
MenuItem.objects.filter(price__gt=450)
Output:
3
<QuerySet [<MenuItem: Chicken Rice Bowl (PKR 650.00)>, <MenuItem: Veggie Pasta (PKR 500.00)>]>

2. List menu items ordered by price, highest first.
Statement:
MenuItem.objects.order_by("-price")
Output:
<QuerySet [<MenuItem: Chicken Rice Bowl (PKR 650.00)>, <MenuItem: Veggie Pasta (PKR 500.00)>, <MenuItem: Grilled Sandwich (PKR 400.00)>]>

3. Find menu items whose name contains "pasta" (case-insensitive).
Statement:
MenuItem.objects.filter(name__icontains="pasta")
Output:
<QuerySet [<MenuItem: Veggie Pasta (PKR 500.00)>]>

4. Get all items of "Main Course" through the reverse relationship.
Statement:
main_course = Category.objects.get(name="Main Course")
main_course.items.all()
Output:
<QuerySet [<MenuItem: Chicken Rice Bowl (PKR 650.00)>, <MenuItem: Veggie Pasta (PKR 500.00)>]>

5. Create an Order (Veggie Pasta, Large) for your student and attach both extras with .add().
Statement:
student = StudentProfile.objects.get(roll_no="BSAI-0066")
veggie_pasta = MenuItem.objects.get(name="Veggie Pasta")
fresh_juice = Extra.objects.get(name="Fresh Juice")
dessert_cup = Extra.objects.get(name="Dessert Cup")
new_order = Order.objects.create(
    student=student, meal=veggie_pasta, size=Order.LARGE, total=800
)
new_order.extras.add(fresh_juice, dessert_cup)
new_order, list(new_order.extras.all())
Output:
(<Order: Order #3 - Veggie Pasta (Large)>,
 [<Extra: Fresh Juice (PKR 180.00)>, <Extra: Dessert Cup (PKR 120.00)>])

6. Show all orders of that student through the reverse relationship.

student.orders.all()
Output:
<QuerySet [<Order: Order #1 - Chicken Rice Bowl (Regular)>, <Order: Order #2 - Veggie Pasta (Large)>, <Order: Order #3 - Veggie Pasta (Large)>]>

7. Using __ lookups, list orders whose meal is in "Main Course" and orders that include "Fresh Juice".

Order.objects.filter(meal__category__name="Main Course")
Order.objects.filter(extras__name="Fresh Juice")
Output:
<QuerySet [<Order: Order #1 - Chicken Rice Bowl (Regular)>, <Order: Order #2 - Veggie Pasta (Large)>, <Order: Order #3 - Veggie Pasta (Large)>]>
<QuerySet [<Order: Order #2 - Veggie Pasta (Large)>, <Order: Order #3 - Veggie Pasta (Large)>]>

8. Use aggregate() to get the sum of all order totals and the average menu item price.
Statement:
Order.objects.aggregate(total_sum=Sum("total"))
MenuItem.objects.aggregate(average_price=Avg("price"))

{'total_sum': Decimal('2430')}
